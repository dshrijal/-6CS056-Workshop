# Workshop 1 - Students & Courses CRUD (Laravel + MySQL)

This package contains every application file for Workshop 1. It is meant to be
copied into a fresh Laravel project (it is not a full Laravel install, because
`vendor/` is generated by Composer).

## Contents
- `app/Models/Student.php`, `Course.php`
- `database/migrations/` - students and courses tables
- `routes/web.php` - all CRUD routes (students + courses)
- `resources/views/student/` and `resources/views/course/` - Blade views

## Setup
1. Create the project (in your workshop repo, on the Workshop1 branch):
   ```bash
   laravel new ./
   ```
2. Copy these files in (from the unzipped folder):
   ```bash
   ./install.sh /path/to/your/laravel-project
   ```
   or copy the folders manually. This REPLACES `routes/web.php`.
3. Configure `.env`:
   ```
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=WorkshopDB
   DB_USERNAME=root
   DB_PASSWORD=
   ```
4. Create the database in DBeaver: `CREATE DATABASE WorkshopDB;`
5. Run migrations and start the server:
   ```bash
   php artisan migrate
   php artisan serve
   ```
6. Open http://127.0.0.1:8000/students and http://127.0.0.1:8000/courses

Note: you do NOT need `php artisan make:model ... -m`; the models and
migrations are already included. If you already ran it, delete the generated
duplicate migration files so tables aren't created twice.

## Fixes vs. the original instructions
- Routes consistently use `/students` (the original mixed `/student`).
- Named route `students.index` added (needed by `redirect()->route(...)`).
- `Rule` is imported; `/students/create` is defined before `/students/{id}`.
- Create validation includes `unique:students` for email.
- Course `is_active` checkbox uses a hidden `0` field so unchecked works.
- Success message is shown on the detail pages after editing.
